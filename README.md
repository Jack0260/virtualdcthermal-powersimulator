# Thermal Guard Pro

Build an advanced, highly efficient data-center management application called "Virtual DC Thermal-Power Simulator" that predicts rack-level power failures and cooling bottlenecks from streaming telemetry.

- Features: 3D-style rack heat map layout, predictive failure analytics engine, and automated cooling threshold alerts.

- UI & Theme: Industrial-grade monitoring UI with a seamless theme toggle for Dark, Light, and System Default modes.

- Requirements: Fully operational interactive controls, zero broken links, robust error handling, and clean responsive architecture.
